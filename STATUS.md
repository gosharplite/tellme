## Branch model

| Branch | Role |
| --- | --- |
| `main` | Stable / released line - each round's `dev` is propagated here (**no-ff**) at its closeout and tagged `round-NNN` (**ADR 0026**). |
| `dev` | Integration line - round work lands here (via the round PR) before `main`. |
| `NNN-*` | The round's working branch, off `dev`; deleted after merge. |

> **Convention**: each round works on its own `NNN-*` branch off `dev`; only a human merges the round PR; propagation is the no-ff merge `dev -> main`, tagged `round-NNN`. Live heads: `git rev-parse --short origin/main origin/dev`. Propagation history: `git tag -l 'round-*'` + the archives.
