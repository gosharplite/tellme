## Last delivered round — 061 `061-mcp-schema-provider-projection` (DELIVERED / FROZEN — PR [#128](https://github.com/gosharplite/tellme/pull/128) merged into `dev` `902642a`, **merge commit**; closes [#127](https://github.com/gosharplite/tellme/issues/127))

- **Theme**: an **operator-observed defect** ([#127](https://github.com/gosharplite/tellme/issues/127)) — with the GitHub MCP server enabled and a `TYPE: gemini` provider selected, **every** turn died (`the provider request failed`, 400, *"Unknown name \"x-mcp-header\" at 'tools[0].function_declarations[7].parameters.properties[0].value.properties[2].value'"*): the server annotates 37 of its 45 tool schemas with the vendor extension `x-mcp-header`, and Vertex parses `functionDeclarations[].parameters` as the **closed** proto `Schema`, so one unknown keyword fails the **whole** `:generateContent` call. The tolerant OpenAI-compatible family never noticed — hence it only broke on Gemini.
- **The change**: **two seams, one concern each** — a **family-agnostic floor** (`mcp.NormalizeMCPSchema` drops `x-…`/`$schema` recursively at **keyword positions only** — a property *named* `x-…` survives; definition maps are traversed) **plus** a **provider-side projection** (`internal/infrastructure/llm/gemini/schema.go`) that is **default-deny on two axes**: the surface's single owner is `supportedSchemaValueKinds` (key → required JSON kind; `supportedSchemaKeys` is derived), the projection keeps only a kind match (measured coercions only — `type` array, `enum` scalars, a non-object schema node → `{}`), and every other mismatch is **dropped**. The gate reads the same owner four ways (containment + value kind + golden set + coverage) + a **round-trip pin** (the projection's own output satisfies the gate).
