| Tool-declaration schema projection (Vertex/Gemini) | Hand-written Go (stdlib `encoding/json`; `internal/infrastructure/llm/gemini/schema.go`) | **Round 061 (issue [#127](https://github.com/gosharplite/tellme/issues/127); ADR 0031 — amends ADR 0025 D1 at the provider wire):** Vertex/Gemini parses `functionDeclarations[].parameters` as the **closed** proto `google.ai.generativelanguage.Schema`, so **any** keyword it does not define makes the API reject the **whole** `:generateContent` call (HTTP 400 → `the provider request failed`, exit 6) and **no** turn reaches the model. The surface’s single owner is a **key + value-kind table** (`supportedSchemaValueKinds`): a value whose JSON kind does not match its field is **dropped** (never emitted — an absent keyword is always accepted), with only the **measured** coercions applied (`type` array — whose lone member must itself be a string, else the keyword drops; `enum` scalars; a non-object schema node → `{}`) — the folds of reviews V-061-1 and W-061-1. The projection is **recursive** (nested `properties`/`items`/`oneOf`/`allOf` subtrees) and **fails closed** (an unparseable/non-object schema degrades to the freeform object — never a new failure mode). It removes **only** keywords: a declared argument keeps its `type`/`description`/`enum`/bounds/nested structure (proving a carve-out, not a lobotomy).
